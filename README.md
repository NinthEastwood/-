# “硬字幕收集器”

作为一个收集爱好者，收藏影视是我电子仓库的重要组成部分。对于一部影视资源来说，字幕的重要性不言而喻。

很多字幕组会把曾经的翻译过的字幕放到相关的字幕网站上面，真可谓是互联网之光啊。可惜我出生的玩没赶上好时候啊。但也有部分字幕组只会压制好的熟肉，这无可非议

就比如曾经的冰冰字幕组，看网上评论得知是一个很好很用心的字幕组，经典作品例如《摩斯探长前传》、《九号秘事》、《布朗神父》、《VIGIL 不眠》、《追凶》

可惜美中不足的是，好不容易才找到的很多资源已经过于陈旧，画质堪忧。

作为一个电子仓鼠，我想的是能不能利用现如今的AI帮我把这些硬字幕抠出来，我再去找合适的生肉，利用ffemp软件封装成MKV文件。

（BTW，这个软件真挺有意思的）
